# Ticks 8..397: the boot signs, as port/input/pad-boot.txt's first phase

# (358 before the boot lost its stage reload and second card check), so the
# title (layout 12) is up at about tick 398 (it was 438) and turns to "New
# Game" only (layout 13) at about tick 461 (it was 501). The boot presses
# end with the START at 394, before the title (as headless_common.py's
# BOOT_LAST 400): a CROSS or START on the title would start New Game.
# Then, a press every 12 ticks or more, each after the screen's fade-in:
#   545  DOWN     the title's cursor from New Game to Settings
#   565  CROSS    Settings (its main page, up at tick 586)
#   605..665      DOWN six times: Display, Audio, Controls, Gameplay,
#                 Language, Achievements to Extras
#   685  CROSS    Extras (Music, Models, Credits, Back)
#   715  DOWN     Models
#   735  CROSS    the model list
#   765  CROSS    the first model (Ico): his host stage loads (up at tick
#                 872) and the viewer shows him
#   1000 CROSS    play the selected animation
#   1060 TRIANGLE back to the model list
#   1100 TRIANGLE back to the title (up again at tick 1182)
