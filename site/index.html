ICO PC

The PlayStation 2 game ICO (PAL), rebuilt from its own code to run on Windows, Linux, the Steam Deck, Android, iPhone and Mac. No emulator: it plays like the PS2 game, with a sharper picture, widescreen and smoother motion when you want them. It needs your own copy of the game disc.

How to install

    What you need

    • Your own disc image of ICO, PAL version (SCES-50760, the number printed on the disc and the case): one file ending in .iso, .chd or .bin (a .bin may come with a .cue). Other regions and editions do not work.
    • About 1 GB of free space for the game's files, which the first start copies out of the disc image.

    The first start

    The game asks for your disc image, then copies the game's files out of it. That takes a minute or two and happens once; after it the game runs without the disc image. On Windows and Linux you can skip the question by putting the disc image beside the program (inside the x64 folder on Windows) named Ico_PAL.iso, .chd, .bin or .cue.

    Before you start

    Needs your own copy of the game disc (ICO, PAL version, SCES-50760) saved as a disc image; see the README.
