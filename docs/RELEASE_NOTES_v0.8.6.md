**Please note:** this release adds two new ways for the game to draw, OpenGL and Direct3D 11, and neither has been run on real hardware: OpenGL has only been checked against the usual picture on a software renderer, and Direct3D 11 has not run on any Windows machine at all, so it may not start or may draw wrongly. Vulkan and Direct3D 12 are as before, and Automatic still starts with Vulkan. If something looks or plays wrong, keep the previous version and send the game's report file (the newest file in the `logs` folder that starts with `report-`, or `ico-pc.log`) with a short description of what you saw. For a problem with OpenGL or Direct3D 11, also send a picture made with **Options > Save a picture for a bug report** (or F12 on a computer), and the lines of `logs/ico-pc.log` that start with `window:`, `rhi_gl:` or `rhi_d3d11:`.

## New

- **OpenGL**, for a graphics card or driver that has no Vulkan, on Windows and Linux. It needs a graphics driver with OpenGL 4.3 or newer; if yours lacks something it needs, the log file names it. If Vulkan will not start at all, Automatic now goes on with Direct3D 12 on Windows and then with OpenGL, and you can also choose it yourself (next item). Reports of how it looks and runs on your card are very welcome.
- **Direct3D 11** on Windows, for a computer that has neither Vulkan nor Direct3D 12. It has never run on any Windows machine, so it may not start and may draw wrongly. It is there for someone to try and tell us what happens. Automatic never picks it.
- **Options > Graphics**, a new page under Effects with a **Graphics API** row: Automatic, Vulkan, OpenGL, Direct3D 12 or Direct3D 11, whichever your download has, used from the next start. Before, this needed an edit to the settings file. It only shows when your download can draw in more than one way. If a choice does not start, pick Automatic again.
- **Apply** on the Graphics page switches to your choice right away, without leaving the game or losing your place. The picture stops for a moment (longer the first time a choice is used), then the page asks whether to keep it and goes back by itself after 10 seconds unless you choose Keep, so a choice that shows nothing on your screen undoes itself. If the choice does not start at all, the game goes back at once, says so and keeps the old choice for the next start. Nothing is saved until you choose Keep, even if the game is closed during the count. This is new and has not been tried on a real computer yet.
- **Options > Graphics driver > Add from the drivers folder**, on Android: copy a driver's zip file into the game's `drivers` folder with a USB cable and add it from there, without the file picker. If the file picker will not open in the box that offers a driver when the graphics do not start, the game uses the first zip in the `drivers` folder.
- **Touch controls:** any button can now be hidden (you do not see it, but it still works) or switched off, the D-pad and Start too, from the layout editor's Opacity keys past the lowest step, and a button can be up to three times its normal size (before, 1.6 times). With the D-pad, Cross or Circle switched off, a tap on a menu line picks it, so the menus and Reset layout stay reachable.
- **Skip the opening**, under Options > Gameplay: the game starts at the title screen, without the Sony sign and the opening scene. Off unless you turn it on; Start still skips the scene by hand.
- **Options > Extras > Export textures**, on the title screen: saves every picture on your disc under the name PCSX2 gives it, in the game's `textures` folder, with a list of what was saved and of what only playing with Dump textures on can add. For people who make texture packs; no developer mode needed. About 160 MB for the European disc. The repository now also carries a spreadsheet per disc of every picture file a pack can hold, where it is used and which pictures share a name, so a pack maker can see what one replacement covers.

## Fixed

- **Options > Extras > Models** no longer closes the game when an animation is chosen that the model cannot play on the stage it is shown in (its movement needs a second animation the stage does not carry). Those animations are now left out of the list, and the log says how many.
- In the Models viewer, the names in the animation list and the Animation line kept their lettering only for a while; after some seconds of play new names were drawn in plain letters, as the frame counter had used up the room the game keeps for its menu lettering. The room is now reused as the counter moves on, so every name keeps the same look.
- Sound should no longer break up at high resolutions (for example 4x anti-aliasing) with a Frame rate of 120 or more. When the extra pictures between the game's own frames start slowing the game down, they are now dropped first and brought back when the graphics card has time again, so the game and its sound keep their speed. This is our best understanding of what was happening and has not been confirmed on the machine that reported it.
- With Vertical sync on, a Frame rate above your monitor's refresh rate (for example 120 on a 60 Hz monitor) now draws one picture per refresh, as Uncapped does, because the monitor could not show more.
- On some Android phones, Add a driver said the file was not a driver when the file picker would not open. It now says what went wrong (the picker did not open, no app on the phone can choose a file, or the file could not be read), tries the phone's other way of choosing a file, and has the new row above for a driver zip copied into the `drivers` folder.
