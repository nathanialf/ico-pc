# Texture catalogue: SCPS-11003

[Back to the texture pack guide](../../TEXTURE_PACKS.md)

This is a list of every picture on the disc `SCPS-11003`: the name the game and PCSX2 give it, and which pictures share one name. A picture that shares a name with an earlier one is covered by the same replacement, so you draw it once.

## How to use it

- A replacement is a picture file named after the texture's name (`<name>.png`, or `.dds`) in the folder `textures/SCPS-11003/replacements`. One file with that name replaces every texture that carries the name, wherever it shows. [How to put a pack in](../../TEXTURE_PACKS.md#put-a-texture-pack-in).
- To get the pictures themselves, choose **Options > Extras > Export textures** on the title screen. The game saves them under these names in `textures/SCPS-11003/dumps`, with a list (`manifest.txt`) of what it saved and left out.
- The group files below list one texture per row: its place on the disc, its format and size, the name of each of its sizes (`name@size number`, 0 being the full size), the first texture that already carries the same name (**Same as**; `first` if it is the first) and notes. A path on the disc is shown without its `model/..` step.
- The **European** column compares with the European disc: `same` when every name of the row also exists there (a pack made for the European disc already covers it), `new` when none does, `partly` when some do.

## What is not on the disc as a picture

Some pictures cannot be listed or exported, because the disc does not hold them:

- the fog, glow, blur and depth-of-field pictures the game draws while it runs;
- the movies;
- the later colours of the textures whose colours cycle (marked `colours cycle`); only the first colours are on the disc;
- names that combine several sizes of one texture (PCSX2 gives them with mipmapping on).

To get these, turn on **Developer mode** and **Dump textures** and play to the place where they show; the game saves them under their names as you go.
