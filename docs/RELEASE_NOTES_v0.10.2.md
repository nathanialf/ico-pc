## New

- Options > Controls > Touch controls has a new choice, Always, Start only in scenes: during a scene only the Start button stays on screen, so it can be skipped.
- Scenery close to the camera no longer vanishes as it did on the PlayStation 2: walls, water and mist are drawn to the edge of the picture, at every aspect and in every preset; the rest of the picture is unchanged.
- On phones, the log now records the graphics chip's clock speed, how warm the phone was and whether the screen was being recorded whenever a picture is held back, and which part of the game (a scene, play, a menu) each ten seconds were in, so stutters can be told apart.

## Fixed

- On phones with a Qualcomm graphics driver and Vsync off, pictures now go to the screen one after another from the start, as the chip maker advises, instead of switching to that only after a few held-back pictures; this is not expected to remove the stutter some of these phones report.
- After the game had turned on its slower, safer graphics mode following two crashes of the graphics driver, it now turns that mode off again by itself after three clean starts.
- Options > Gameplay > Time to rescue Yorda is now set in seconds and changes the whole pull-in; before, only its last moment changed.
- On phones with only two fast processor cores, the game's main work now runs on them.
- The text effect now takes phones a fraction of the time to prepare; the picture is the same.
- On phones with an older PowerVR graphics driver (Motorola with a MediaTek Dimensity 7020, for one) the game no longer stops before it starts: the first thing it prepared was a text effect the phone's menus do not use at this size, and the game now gives this driver more time.
- On phones the picture is now handed to the screen already turned the way the screen is held, so the system no longer turns it again on the graphics chip.
- Near the exit of the cave (stage 32), a wide picture no longer shows lighter grey bars at its sides: the mist now covers the whole picture, in the middle as at the sides.
- At the castle's main gate, seen from the sofa in a wide picture, the gate's bottom beam no longer shows a strip of the stone step behind it: a beam corner very close to the camera made the beam look further away than it is.
