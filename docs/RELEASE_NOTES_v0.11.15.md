## New

- Options > Controls > Zoom type: choose Toggle to press the zoom button (R2) once to zoom the camera in and again to zoom it out, instead of holding it.

## Fixed

- An attempted fix for short freezes in the title and menus on some Android phones after a slow picture, when the game made its background copy.
- An attempted fix for the stutter in the boat scene on phones like the moto g24: the skipping of tiny pieces of the picture added in the previous version did not help there, so the game now measures it while you play and uses it only in the places where it makes the game faster.
- An attempted fix for the stutter in busy scenes such as the boat on phones like the moto g24: some of the scenery is now drawn in a way that can let the graphics chip skip hidden parts sooner; it checks itself when the game starts, measures itself while you play, and stays off where it does not make the game faster or after a graphics problem.
