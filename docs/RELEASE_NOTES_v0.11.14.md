## Fixed

- An attempted fix for the game pausing for a moment after a brief graphics stall on some Android phones (the opening cinematic on a Mali phone): the game's own background copies and automatic captures no longer wait for the slow picture to finish.
- An attempted fix for the unsteady frame rate in busy scenes on some phones like the moto g24, such as the boat in the opening: the game no longer asks the graphics chip to draw the tiny pieces of scenery that are too small to show up in any pixel. It checks itself at start-up and turns this off if anything looks wrong, and keeps it off until the next version if the game closes with a crash or a graphics problem while it is in use.
- An attempted fix for uneven speed in the opening cinematic and for the slowdown in ordinary play that the previous version brought to some Android phones (a Mali phone) with Frame rate Original: the next picture now goes to the graphics chip while the one before is still finishing, so that the chip does not sit waiting between pictures. If the game closes with a crash or a graphics problem while this is in use, it stays off until the next version.
- An attempted fix for the missing room in the dream at the start of the game with the North American disc: its walls, floor and windows are drawn again around Ico instead of an empty cloudy sky.
