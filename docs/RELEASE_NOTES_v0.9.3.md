**Please note:** The fix below has not been tried on a real AMD Radeon RX 7000 graphics card, because no such card was available while it was made. The cause was found in the graphics driver's own source code, and the game's drawing tests pass on the other drivers. If the picture is still striped for you with Vulkan, please send `logs/ico-pc.log` from a start with Vulkan.

## Fixed

- On AMD Radeon RX 7000 graphics cards on Linux with the Mesa 25 drivers, Vulkan drew every other column of the picture black with bright dots, on every screen from the title on. The game left a blending setting from the previous drawing step in place while blending was off, and that driver treated the step as two-colour blending, which these cards handle by pairing neighbouring pixels. The game now clears the setting, so the picture is whole on those drivers too. OpenGL was not affected, and the Mesa 26.2 drivers already drew it right. The game's start-up drawing check now also looks for this fault, and if a driver still shows it, the game switches to a slower way of blending that avoids it.
