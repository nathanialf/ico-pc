## New

- A Water reflections row on the Effects page (Options > Effects): Original keeps the game's soft reflections, Sharp draws them at your resolution.

## Fixed

- The first start after an update no longer takes minutes on phones, and it shows how long is left while the game prepares its graphics. It also no longer closes on some Android devices while preparing its graphics.
- The trolley's wheels no longer jump back and forth when it moves at full speed.
- For the graphics card error as the title appears on some phones, and the crash while preparing graphics on NVIDIA GeForce 10-series cards: the game's shaders are now written the way the last version that ran on those devices wrote them. Please report if either still happens.
- When the graphics driver stops responding, the game now keeps a file next to the log that shows what it was drawing. Please attach it to your report along with the log.
