## Fixed

(kept current after every merge; player words only)

- The game no longer hitches when it saves a diagnostic capture; on phones the pictures it saves automatically for a report are written in the background, and the Settings bug-report picture now brings the newest of them along, so one attachment is enough.
- On phones with a fast screen (90, 120 or 144 Hz), Frame rate Original now asks the screen for 60 Hz (50 Hz in the European 50 Hz mode), a rate the game's pictures divide evenly, where it asked for nothing before; the log also counts the long freezes reported on some Snapdragon phones per minute, by screen rate.
