# Divergences from the PS2

Every way the port's behaviour or output differs from the PS2 PAL release, SCES-50760, as the code
stands: where it happens, what each side does, whether game state can follow, and how to see it.
Places where the port reproduces the PS2 are not listed. A log line may cite a row by id: the
display-list line of VD-5 does (`ico2/seki/src/DisplayList.c` (`dlHostFull`)). Ids are never reused
or renumbered.

## Standard

The rows are measured against this standard: discrete game state (integers, flags, random number
state, object and state-machine state, timers) is the PS2 PAL release's in the default game unless a
row says otherwise. No test compares a run with the PS2; the traces
([TESTING.md](TESTING.md#pad-scripts-recordings-and-the-trace)) compare runs of the port.
Floating-point results follow the [EE](ARCHITECTURE.md#terms)'s FPU and [VU0](ARCHITECTURE.md#terms)
as modelled in `port/math/ps2float.h`, at the sites that call the models, and plain IEEE arithmetic
under the simulation's FP mode elsewhere ([MATH.md](MATH.md)).

## How to add a row

One row per divergence, in the section of its area, with the next free id of that area (`GL-n` game
logic and the game's own screens, `VD-n` video, `FP-n` floating point, `AU-n` audio, `TM-n`
timing). The columns:

| column | what goes in it |
| --- | --- |
| id | the area's prefix and the next number; a removed row's id is not given out again |
| area | the part of the PS2 or the game it concerns |
| site | `path (symbol)`, several when the behaviour spans files; symbols, never line numbers |
| PS2 | what the original does, and where that is stated (a code comment, psx-spx (the public PlayStation hardware reference, [../LEGAL.md](../LEGAL.md)), a `.vsm`, `port/math/ps2float.h`'s model) |
| port | what the port does, from the site's own comment or code |
| discrete state | `no` (picture, sound or timing only) or `yes: <what>` (the state the difference can reach) |
| how it shows | the log line, ctest or option that makes the difference visible, quoted as in the code |
| status | `accepted` (the difference is meant or tolerated) or `to check` (the code calls it unverified or not known, or the PS2 side is stated nowhere in the tree) |

A difference that cannot be shown by a log line, a test or an option is not a row. A behaviour a
config key turns on goes in [Options that change behaviour](#options-that-change-behaviour),
keyed by the config key.
