**Please note:** this release has had only limited testing: one computer and automated checks. It may look or play wrong in places the previous version did not. If it does, keep the previous version and send the game's report file (the newest file in the `logs` folder that starts with `report-`, or `ico-pc.log`) with a short description of what you saw.

## New

- **Options > Controls > Hold type** now shows from the title screen as well as the pause menu, and is kept in the settings file instead of your save, so it stays as you set it whatever save you load. **A (hold)** keeps Yorda's hand while R1 is held down, as the European and Japanese discs do; **B (toggle)** takes her hand with one press of R1 and lets go with another, as the North American disc does. On a phone, B means you tap R1 instead of keeping a finger on it. Its note now says how both choices work.
- **Options > Controls > Touch screen**, a new page that holds the three touch rows (Touch controls, Touch size, Touch opacity) and a way to arrange the on-screen buttons yourself. **Edit layout** opens an editor: tap a button to select it, drag it to move it, pinch it (or use the Size keys) to make it bigger or smaller, and use the Opacity keys to make it more see-through. **Snap to grid** and **Grid size** line the buttons up, **Undo** takes back the last eight changes, and **Reset layout** and **Reset all layouts** put the game's own places back. Select, L1, L2, R2 and the look pad can be hidden. The D-pad, the four face buttons, R1, Start and the stick cannot, and never go below 25 % opacity, so you can always reach the menus. A button cannot leave the screen or sit on a fold, and cannot be dropped onto the middle of another. Every way you hold or fold the phone has its own arrangement, kept in the settings file, and a gamepad can drive the editor too. The buttons are where they were until you change them.
